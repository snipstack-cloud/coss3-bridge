# --- идея split_control: раздельное управление, от игрока 27.09 (§13ч) ---
#
# ОТКУДА. Слова игрока: «опытный игрок играет мушкетёрами и пикинёрами
# раздельно; мушкетёры перестреляют пику на подходе, но если пика доберётся,
# мушкетёры бесполезны». Код согласен: radiusmin мушкетёра 300 пикселей = 5,6
# клетки, ближе он не стреляет, а отходит (unit.script:7898).
#
# ЗАМЕР, который делает идею нужной: за 227 партий модель указывала вид бойцов
# полем who ДЕВЯТЬ раз, и всегда пикинёров. Стрелками отдельно не ходила ни
# разу, хотя мост умеет это с 20.09. У базы no_gather таких приказов ноль.
#
# ЭТА СЕРИЯ — ЕЩЁ И ЗАПИСЬ ДЛЯ СИМУЛЯТОРА. Закон тыловой поддержки стрелков
# написан и выключен: проверить его нечем, потому что случая «пика в контакте,
# стрелки в шести клетках позади» в архиве нет. Эта серия его создаёт.
#
# Мера названа ДО прогона, в скобках no_gather (bed4de0), три копии:
#   1) МЕХАНИЧЕСКАЯ: тактов с приказом по виду (0/0/0) — ждём больше нуля в
#      каждой копии, иначе идея не доехала;
#   2) тактов, где наши стрелки и пикинёры в РАЗНЫХ клетках — ждём больше нуля;
#   3) размен, его потери на нашу (1,06/0,67/0,55) — ждём выше;
#   4) наши потери (173/232/174) — ждём НИЖЕ, это и есть смысл идеи;
#   5) убито крестьян (117/95/5);
#   6) КОНТРОЛЬНАЯ: время первой волны (277/278/276 с) — раздельные приказы не
#      должны её задерживать.
[война] Води пикинёров и мушкетёров РАЗДЕЛЬНО, двумя приказами в такте. Поле
   who говорит, кем выполнять: {"cmd":"ATTACK","count":"all","who":"infantry17",
   "target":"cell","cx":X,"cy":Y} для пикинёров и отдельный приказ
   {"cmd":"ATTACK","count":"all","who":"musk17","target":"cell","cx":X2,"cy":Y2}
   для мушкетёров, где клетка мушкетёров в 6-7 клетках ПОЗАДИ пикинёрской, на
   линии к нашей базе. Мушкетёр ближе 6 клеток к бою не стреляет, а отходит:
   подпущенный вплотную, он уже не боец. Пикинёры держат контакт, мушкетёры
   бьют подходящих из-за них. Когда бой сместился — переставь мушкетёров, снова
   на 6-7 клеток позади. Если нападают на нашу базу, встречай мушкетёрами с
   дистанции, а пикинёров держи в контакте
   ДЛЯ ВТОРОГО ПРИКАЗА НУЖНЫ МУШКЕТЁРЫ. Без них приказ who=musk17 не берёт
   никого и идея проверяется вхолостую: замер 19.09 — при нуле мушкетёров такой
   приказ взял ноль бойцов, а серия food_share2 27.09 дала стрелков 0 / 0 / 129
   на три копии, то есть модель может не взять их вовсе. Если стрелков нет —
   закажи их (TRAIN musk17), для них нужна угольная шахта; и только потом
   раздельные приказы.
