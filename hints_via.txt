#

# заказана всего в 5 волнах из 26, и разница между «с ней» и «без неё» видна
# в самих числах моста:
#   марш t0=271: послано 21, у сбора 21, в поле при ударе 21, удар через 96 с.
#              Кулак дошёл ЦЕЛИКОМ. Вердикт цели «можно», перевес 2.0, потерь 0.
#   без сбора  (урок самой модели в той же серии): «ATTACK без via при 122
#              бойцах дал растянутую цепочку от 71 до 120 от базы и ноль убитых
#              крестьян».
# Растянутость мерена ещё 16.09: пока шли двое - разрыв 3 единицы, с пятерых -
# 22, и эти 22 держатся всю дорогу. Опоздавшие не догоняют, хвост в бою не
# участвует. Сбор - единственная механика моста, которая это лечит.
#
# Механизм из кода, а не догадка (llm_policy, фазы марша). via - клетка сбора:
# бойцы идут туда БЕЗ боя, мост ждёт, пока подтянутся, и только потом ведёт их
# на цель одним кулаком. Пока идёт сбор, порог hold_if_outnumbered
# перепроверяется каждый такт, и если у цели стало слишком много врага, мост
# исполняет if_held сам.
#
# ЧЕСТНОЕ ПРЕДУПРЕЖДЕНИЕ, тоже из замеров: сбор не бесплатен. Двa марша из пяти
# в той же серии ИСТЕКЛИ, и оба - по одной причине, слишком далёкая клетка
# сбора при слишком коротком сроке:
#   t0=436: via (12,8) при цели (12,14), expires 150 - за 151 с у сбора 0;
#   t0=654: послано 108, expires 120 - за 120 с дошли 65 из 108.
# Отсюда и сказано модели: клетку сбора ставить на СВОЕЙ половине пути, а срок
# давать с запасом. Своих чисел про «сколько именно» у проекта пока нет - их и
# должна дать эта серия.
#
# Чего НЕ говорим: когда бить, сколько вести и по какой цели. Это выбор модели;
# клетку сбора она тоже выбирает сама, мы говорим лишь, что её стоит назвать.
#
# Мера идеи, названа ДО прогона (в скобках assess_local, 9 партий):
#   1) доля волн, отданных с клеткой сбора: 5 из 26;
#   2) доля маршей, дошедших до фазы «удар»: 2 из 5, истекли 2;
#   3) сколько бойцов у сбора в миг удара против посланных - кулак целиком?
#   4) дошедших волн (mil_far>=180) 1 из 26, вех 2, потерь на волну 4,2;
#   5) контроль: волн на партию 2,9, цель 0 из 9.
