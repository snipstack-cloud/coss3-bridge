# Дописка для идеи exchange_hint (ключ --hints-extra), ставится ПОВЕРХ базы одна.
#
# Откуда взялось. outcome_report.py по трассам parallel_start и base15, 117 волн
# (18.09): у базы врага его армия ЗА ТАКТ НЕ УБЫВАЕТ НИ РАЗУ - 0 волн из 117.
# Всё, что наши волны там делают, видно только по крестьянам: убыло 25 за две
# серии. Вся убыль армии врага (58 в parallel_start, 12 в base15) случилась,
# когда наша армия стояла ДОМА, то есть когда он пришёл к нам сам. Волны «в
# пути» - 56 процентов всех - не убили ни одного бойца и ни одного крестьянина.
# Игрок мерил то же вручную: размен дома 0,67 врага за нашего, в походе 0,19.
#
# Что это значит для решения. Поход к базе врага - худшее из трёх действий по
# замеру, а не по мнению; лучшее - принять его у себя. Но одной обороной не
# выиграть: он прирастает на 15,9 бойца в минуту против наших 4,4, и крестьян
# у него становится только больше. Поэтому подсказка не «сиди дома», а «не
# трать кулак на поход, который по числам ничего не даёт».

РАЗМЕН ПО МЕСТУ, ИЗМЕРЕНО НА 117 ВОЛНАХ. У базы врага твоя волна НЕ УБИВАЕТ его
бойцов - ни разу за 117 волн; там она лишь тает. Волна «в пути», растянувшаяся
цепочкой, не убивает никого - ни бойцов, ни крестьян. Всё, что ты убил за две
серии, убито У СВОЕЙ БАЗЫ, когда он пришёл сам. Отсюда правило: не шли волну,
которая придёт к нему цепочкой или меньше его защитников у цели. Либо один
кулак, который у цели больше его армии (смотри сетку сил вокруг цели), либо
копи дома и бей его, когда он придёт к тебе, - это единственный размен в твою
пользу. Крестьян врага убивает только волна, которая ДОШЛА целой.
