## Правка

* `strategy_live._тактика`, удар по лагерю: ключ `гарнизон_свободными` 1 (0 — как было). При `лагерь_гарнизон` > 0 и
  отряде дома приказ несёт `all` (каждый отряд целиком, удержание снято), числом — только бойцы вне отряда сверх
  гарнизона (не меньше 1). Прогноз — по тем, кто уйдёт: отряд + число. Селфтест `selftest_гарнизон_свободными.py` на
  настоящих состояниях storm_pol 15:00–17:10 (`sim/кейсы/капля_storm_pol_1500-1710.jsonl`): без ключа — «167 без all
  при 8 свободных» (капля воспроизведена), с ключом — `all`, count 1. Все 184 селфтеста зелёные.
* `sim/поиск/ветка_казарма3_без_капли.json` — файл для живой партии ПЛАН (103) п.4: ветка_казарма3 + ровно три ключа
  (`штурм_всем` 1, `штурм_при` 0,92, `гарнизон_свободными` 1). В самой ветке_казарма3 обе причины на месте.
