## Механизм (код)

`strategy_live` — фильтр ручейка: каждый такт прогноз считается для приказа «атаковать клетку X» по силе приказа —
для приказа из дома это `из дома N`, только оставшиеся дома. Если прогноз ниже порога, а к этой цели уже идёт выход
(`отход_поля`), правило §170л (в) отзывает домой ВСЕХ в поле. Пример: drop_pol 22:20 — «НЕ_ВЫГОДНО из дома 98 против
его 191, R 0,64» → «ВЫХОД ОТМЕНЁН: наших в поле 613, все домой». Через такт дома снова много — выход снова выгоден.
Вопрос «посылать ли подмогу из дома» и вопрос «продолжать ли выход» решались одним прогнозом по неверному множеству.

## Правка

`strategy_live`, ветка отмены выхода, три ключа (все 0 — как было):
* `отход_по_всем` 1 — продолжать ли выход, судится прогнозом по полю (`ocells` дальше клетки от дома) + силе приказа
  (для приказа группе в поле — только поле, без двойного счёта); прогноз «из дома» решает только подмогу;
* `отход_запас` k — отзыв только при прогнозе ниже k × порога (гистерезис);
* `отход_не_раньше` T — первые T секунд после выхода не отзывать.

В файл живой партии — только `отход_по_всем` (обе модели: корень — множество). Селфтест `selftest_качели.py` на тактах
drop_net 19:30–22:30 и drop_pol 20:00–22:30 через полный `ответ()`: без ключа отмена воспроизводится, с ключом —
«ВЫХОД ПРОДОЛЖЕН: поле + дом 376 против 127, R 2,46» и «711 против 191, R 9,84»; если с такта отмены его у цели
вдесятеро — отзыв остаётся. 186 из 186 зелёные. Файл `sim/поиск/ветка_казарма3_без_качелей.json` (= `_зона` + этот
