# Развернуть мост на Windows для хакатона (7.11)

Схема: игра без правки файлов, наш код подключается при запуске ключом `-startscript` (как у официального «01 AI bot»).
Контрольная сумма скриптов остаётся исходной, поэтому сетевая комната пускает. Нация — Польша.

Пути ниже — как на машине игрока; если другие, поправить:

```powershell
$repo = "C:\Users\LapSt\Downloads\coss3-git"
$game = "C:\Program Files (x86)\Steam\steamapps\common\Cossacks 3"
```

## 1. Свежий мост

```powershell
cd $repo
git checkout master
git pull
git log --oneline -1          # должен быть не старше 80e7b74
```

## 2. Игру — к исходным файлам

Игра и официальный «01 AI bot» закрыты.

```powershell
python install_bridge.py $game --uninstall
```

Затем Steam → Cossacks 3 → Свойства → Установленные файлы → «Проверить целостность файлов игры».
Это гарантирует исходные `progress.inc`, `doprogress.inc` и `lib/miscext2.script`: от них зависит сумма.

## 3. Собрать загрузчик в папку игры

```powershell
python загрузчик.py $game
```

Ожидается строка `собрано: …\work\coss3\loader.pas (7622 строк такта …)`.
Если отказ в доступе к Program Files — запустить PowerShell от администратора и повторить.

## 4. Запустить игру с загрузчиком

Через Steam (Steam открыт), как это делает официальный бот:

```powershell
& "C:\Program Files (x86)\Steam\steam.exe" -applaunch 333420 -startscript "$game\work\coss3\loader.pas"
```

Запасной путь — напрямую из папки игры:

```powershell
cd $game
.\cossacks.exe -startscript work/coss3/loader.pas
```

## 5. Проверить, что загрузчик встал (в главном меню)

```powershell
Get-Content "$game\work\coss3\loader.cfg"
Get-Item "$game\coss3_hb.dat" | Select-Object LastWriteTime, Length
```

В `loader.cfg`: `setup_complete = 1`; `library_before`, `library_after_setup` и `cached_library_digest` одинаковые.
`coss3_hb.dat` обновляется. Файла `@@OUT@@coss3_hb.dat` быть не должно.

Если `rejected_reason`:

| причина | что делать |
|---|---|
| `base_scripts_differ` | файлы игры не исходные — шаг 2 |
| `native_compile_preflight` | такт не компилируется — прислать хвост лога игры |
| `camera_has_existing_behaviours` | запущен официальный бот — закрыть его и игру, повторить |
| `main_menu_only` | загрузчик стартовал не в меню — перезапустить игру |

## 6. Мост ведёт партию

В отдельном окне PowerShell, до создания комнаты:

```powershell
cd $repo
python сетевая_партия.py --dir $game --один
```

Пускатель печатает лобби при каждом изменении. Дальше в игре: сетевая игра → создать комнату (мост работает только у ХОЗЯИНА
комнаты), себе — Польша, старт. На `started` пускатель сам запускает политику со стратегией `польша_судья_по_врагу.json`.
Платных вызовов модели нет.

## 7. Что проверить в первой партии

1. Комната пускает другого участника (сумма сходится) — главное, ради чего всё.
2. `coss3_eco_P<слот>.dat` обновляется раз в секунду.
3. Ратуша и мельница заложены на первом такте, крестьяне идут на работу, в логе пускателя идут такты стратегии.
4. После академии в `squads_list` появляется колонна SQUARE36, в `squad_real_dmg/def` — 2 и 2.

## Чего пока нет

* **Бот у клиента.** В чужой комнате, где вы не хозяин, бот не поведёт: блоки закрыты для клиента (разбор в ПЛАН, (296)).
* **События гибели** (`block_kills`): правка библиотеки игры ломает сумму, в загрузчик не входит.
* **Конец партии для фермы** (`block_endgame`): не входит. Для живой партии не нужен.

Откат на прежнюю схему с правкой файлов (сумма снова будет своя):
`python install_bridge.py $game --reinstall --human-only --human-state --human-cmd --endgame --human-kills`
