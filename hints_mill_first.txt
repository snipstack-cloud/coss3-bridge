# Дописка для идеи mill_first (ключ --hints-extra), ставится ПОВЕРХ base15 одна.
#
# Откуда взялось. Замер по 15 партиям base15: мельница готова на 64-й секунде,
# поле после неё зреет ещё около 105 секунд, и только на 170-й секунде первый
# крестьянин встаёт на еду. Всё это время еда падает, а ниже 500 не идёт НИКАКОЙ
# наём - ни крестьян, ни бойцов. Выход из голода наступает на 207-й секунде.
#
# Почему это важно. Секунда, на которую мельница встала раньше, сдвигает выход
# из голода один в один: поле начинает зреть раньше. Ратуша готова уже на 27-й
# секунде, то есть между ней и мельницей есть тридцать с лишним секунд, которые
# сейчас уходят на другое.

МЕЛЬНИЦА ПЕРВОЙ. Сразу после ратуши ставь мельницу и веди на неё столько
строителей, сколько есть свободных. Поле сеется само, когда мельница достроена,
и зреет ещё около ста секунд - до этого на еду поставить НЕКОГО, сколько ни
приказывай. Чем раньше встанет мельница, тем раньше кончится голод, а пока он
идёт, наём стоит целиком.
