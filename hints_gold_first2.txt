#
# Что происходит без неё:
#
#   | | без золотой шахты | с золотой шахтой |
#   | партий | 8 | 25 |
#   | из них БЕЗ КАЗАРМЫ вовсе | 3 | 0 |
#   | армия максимум, медиана | 14 | 58 |
#
# Механизм виден по тактам, а не выведен: стартового золота 1000, казарма стоит
# 500, приход без шахты нулевой, и золото только убывает на крестьян. В партии
# base8/2.1 модель заказывала казарму СЕМЬ раз и не построила ни разу, имея к
# концу 42 крестьянина; в upgrades/4.1 - 59 крестьян и ноль армии. Это не
# «задавили в начале»: экономика была цела, солдат оказалось негде делать.
#
# Почему не повторение mines2. Та идея гнала «больше шахт» вообще: их стало 4,3
# против 2,0, в шахтах заперлось 13 крестьян из 30, армия упала вдвое, а ПЕРВАЯ
# ВОЛНА ушла на 532-й секунде против 395-й - и цель просела с 4 из 6 до 1 из 6.
# Здесь речь про ОДНУ шахту и про РАННЕЕ время, а не про число. Поэтому время
# первой волны стоит в мере: если оно поедет вправо, идея проиграла, чем бы ни
# кончились остальные числа.
#
# Строка НЕ велит ставить шахту в определённый момент и не называет числа шахт:
# когда и сколько - решает модель, как и в iron_first.

# убирает подсказку, как только звено пройдено (llm_policy.отобрать_подсказки),
# а этот совет с казармой не истекает: из восьми партий без золотой шахты в ПЯТИ
# казарма стояла, и армия всё равно вышла 14 против 58. Золото после казармы
# тратится на бойцов (пикинёр 3, мушкетёр 8) и апгрейды. Цена всегда видимой
# строки - около 150 токенов в такте при SYSTEM в 6600, то есть примерно 2%.
#
# Мера, названа ДО прогона (в скобках base8, 9 партий):
#   1) доля партий с золотой шахтой (8 из 9) и КОГДА она встала (медиана 358 с);
#   2) доля партий с казармой (8 из 9) и когда (медиана 280 с);
#   3) армия максимум, медиана (60);
