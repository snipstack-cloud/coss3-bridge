# hints_fighters.txt.
#
# Откуда взялось. 14.09 серия fighters: модель впервые увидела список бойцов и
# заказала мушкетёров 12 раз против нуля в базе - и сама назвала причину, по
# которой волны никого не убивают: «Пикинёр бьёт только вплотную, а крестьяне
# убегают; нужны стрелки (musk17) или большая волна».
#
# Проверено по коду в тот же день, и она права:
#   gc_unit_runawaydist = 3.5, gc_unit_runawaydelay = 1.3  dmscript.global:198
#   отход включается для юнита БЕЗ bstandground             unit.script:7367
#   у пикинёра и мушкетёра bstandground := True             unit.script:637, :783
#   у крестьянина его нет - значит он отбегает
# Пикинёр бьёт в радиусе 35-100, мушкетёр стреляет со 120.
#
# Это объясняет главный замер проекта лучше, чем «у базы охрана»: за 18 партий
# 1139 бойцов ушли в волнах и не убили НИ ОДНОГО крестьянина.
#
# Строка НЕ велит набирать стрелков: сколько их нужно и по карману ли они при
# пороге еды 500 - решает модель. Мера идеи - убитые крестьяне врага.
#
# Метки звена нет нарочно: [армия] закрывается при первом же бойце.
крестьянин не стоит и не ждёт: при опасности он ОТБЕГАЕТ, и догнать его
   пикинёру нечем - тот бьёт только вплотную. За 18 партий 1139 наших бойцов
   ушли в волнах и не убили ни одного крестьянина. Мушкетёр стреляет со 120,
