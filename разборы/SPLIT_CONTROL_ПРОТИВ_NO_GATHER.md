# `split_control` против `no_gather`: идея НЕ ДОЕХАЛА, потому что противоречит мосту

3 копии, 27.09, мост `754ee86`. Задание мака (§13ч) со слов игрока: пикинёры
держат контакт, мушкетёры бьют из-за них с 6–7 клеток, два приказа `ATTACK` в
такте с разным `who`.

## Механическая мера ПРОВАЛЕНА: приказов по виду 1 / 0 / 0

Ждали больше нуля в каждой копии (у базы 0 / 0 / 0). Поле `who` в трассе пусто в
50 из 51 такта у первой копии и во всех 51 у второй и третьей.

**Причина найдена, и она не в модели: подсказка требует того, что мост запрещает.**
Строка запроса (`llm_policy.py:368`) говорит прямо:

> ОДИН удар за такт: файл приказа один, и два ATTACK в одном ответе не ужиться —
> выполнится последний, а про остальные мост скажет вслух. Нужны два разных вида в
> разные клетки — отдавай их РАЗНЫМИ ходами.

А подсказка просит «двумя приказами в такте». Модель читала оба текста и не делала
ни того, ни другого: свои уроки она тратила на то, чтобы ДОБЫТЬ мушкетёров, и один
раз прямо написала «казарма №2 и кузница стоят, стрелков 76 — второй приказ по
`who` сработает», но второго приказа так и не отдала.

## Что при этом изменилось — и это МОЯ вторая разница, признаю

| | `split_control` | `no_gather` |
|---|---|---|
| стрелков максимум | **99 / 94 / 92** | 42 / 55 / 19 |
| пехоты максимум | 84 / 119 / 83 | 199 / 127 / 171 |
| убито крестьян (счёт движка) | 65 / 37 / 78 | 122 / 97 / 10 |
| размен | 1,06 / 0,33 / 0,35 | 1,06 / 0,67 / 0,55 |
| наши потери | 156 / 183 / 216 | 173 / 232 / 174 |
| первая волна | 317 / 712 / 426 с | 277 / 278 / 276 с |

Строку «для второго приказа нужны мушкетёры» дописал я — из-за `food_share2`, где
стрелков вышло 0 / 0 / 129. Она сработала слишком хорошо: стрелков стало 92–99
против 19–55 у базы, а пехоты вдвое меньше. **Это и есть вторая разница**: плечо
вышло про СОСТАВ, а не про раздельное управление, и мерить им раздельность
нельзя. Формулировка «условие исполнимости» меня не оправдывает — состав
изменился измеримо.

Исход при этом не улучшился: размен ниже базы в двух копиях из трёх, первая волна
позже во всех трёх (в копии 2 на 712-й секунде — модель ждала мушкетёров).

## Что делать

1. **Переформулировать подсказку под мост:** пикинёрам приказ одним ходом,
   мушкетёрам — СЛЕДУЮЩИМ. Волна между тактами не рассыпается, механизм «стрелки
   в шести клетках позади» от этого не страдает. Это бесплатная правка, и она
   снимает противоречие, из-за которого серия не доехала.
2. **Либо учить мост двум ударам за такт** — но это файл приказа, то есть правка
   `.inc` и новая живая проверка; браться за неё стоит только если переформулировка
   не поможет.
3. Повтор гнать БЕЗ моей строки про мушкетёров, либо с ней у ОБЕИХ сторон — иначе
   разниц снова будет две.
