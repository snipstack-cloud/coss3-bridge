# Разборы трасс локальной моделью

Разбор ОДНОЙ отыгранной партии моделью `qwen3:30b-a3b` на маке: что в партии
выглядит странно. Инструмент — `../разбор_трассы.py`, запуск:

    python3 разбор_трассы.py ~/coss3-res/<дата>/<идея>/<копия>/coss3_bot.jsonl
    python3 разбор_трассы.py <...> --сухой     # только выжимка, без модели

Зачем локальная модель: трасс 146, тактов 17901, разбор задним числом ничего
не стоит и может идти ночью. Цена одной партии — около 11 минут (52 такта,
выжимка 8,6 тысячи символов, рассуждение 2900 слов).

## Порядок, и почему он такой

1. **python собирает выжимку** из полей трассы: состояние, команды, отказы,
   события, потери. Слова модели (`why`, `lesson`, `idea`, `critic_hyp`) в
   выжимку НЕ идут — иначе разбор пойдёт по её вере, а не по игре.
2. **модель ищет странности** и обязана к каждой дать «как_проверить» — меру,
   считаемую по МНОГИМ тактам. Без меры находка отбрасывается здесь же.
3. **счёт руками** — и только после него находка становится находкой. Раздел
   «Проверено счётом» дописывается в файл разбора ПОСЛЕ прогона; перезапуск
   разбора его затрёт, это плата за простоту.

## Что уже стоило нам трёх ложных находок

Первый заход 22.09 дал 3 находки из 3 ложных, и виноват был инструмент:
в трассе команды лежат ЧИСЛАМИ (`BUILD 4/1` — роль №4, всего 1), а выжимка
показывала их как есть. Модель прочитала числа как количество зданий, сложила
4+14 и построила на этом всю арифметику. После расшифровки имён (`BUILD mill
всего 1`) те же 52 такта дали 3 находки, и все три подтвердились счётом.

**Вывод, который стоит помнить при любом расширении:** ложные находки здесь
рождаются не из глупости модели, а из нечитаемой выжимки. Прежде чем винить
модель — прочитать выжимку самому.
