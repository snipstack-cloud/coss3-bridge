# Как НЕ считать походы (24.09)

**Коротко.** Походы нельзя сводить по `t0`: это якорь СРОКА, и сброс срока его
двигает. Считать надо по полю `поход`, которое мост пишет с 24.09.

## Как нашлось

Разбор `wave_resets` против `wave_march`. Главная мера плеча — доля походов,
кончившихся хоть чем-то. Посчитал тремя защитимыми способами и получил три
разных ответа на одних и тех же одиннадцати трассах:

| способ | база `wave_march` | идея `wave_resets` |
|---|---|---|
| по `t0` (так считал `assess_report`) | 154 похода, 8 % дошли | 65, 22 % |
| непрерывная череда тактов с маршем | 10, 70 % | 14, 71 % |
| по падению `сбросов` в ноль | 21, 57 % | 37, 86 % |

Ни один не воспроизводит числа из итога 24.09 («13 из 13 против 7 из 15»), то
есть тот итог опирался на счёт, который не восстанавливается.

## Почему `t0` негоден — доказательство, а не довод

В базе один и тот же поход идёт с растущим `t0`:

    gt 541  t0 540  сбросов 0  фаза сбор
    gt 561  t0 545  сбросов 1  фаза сбор
    gt 581  t0 574  сбросов 2  фаза сбор
    gt 601  t0 588  сбросов 3  фаза сбор
    gt 621  t0 609  сбросов 4  фаза сбор
    gt 626  t0 625  сбросов 5  фаза сбор

Шесть «походов» вместо одного. Это делает строка `МАРШ["t0"] = int(gt)` в
ветке продления срока.

**И это не просто неточность.** Сбросы режет ровно тот ключ, который и
проверялся (`--gather-resets`): у базы сбросов до 35 на поход, у идеи не больше
одного. Значит счёт по `t0` завышает знаменатель тем сильнее, чем СЛАБЕЕ ключ,
и сравнение плеч этим числом измеряет собственный артефакт. Разница вышла
десятикратной.

## Что сделано

* мост пишет `поход` — номер, растущий ТОЛЬКО в `начать_марш`, и `t_старта` —
  настоящее начало (в отличие от `t0`, который уезжает при каждом сбросе);
* `assess_report.марши()` сводит по `поход`, а на трассах старше 24.09
  **говорит вслух**, что считает по `t0` и что число завышено — молчаливого
  смещения больше нет;
* самопроверка `selftest_march_id.py`.

## Что из этого следует для прежних выводов

Все числа про «походы», снятые до 24.09, считаны по `t0`. Устойчивым при любой
группировке остаётся немногое, и только это можно брать на веру:

* **истечений у базы НОЛЬ при любом способе счёта**, у идеи 2–18 — выход у
  похода появляется только с ключом, и это механическое обещание выполнено;
* **удары на копию равны**: база 2,4 против идеи 2,3 (по `t0`), 1,4 против 1,33
  (по череде) — предел не режет живые походы.

Доли же («47 процентов», «100 процентов») перемерить по старым трассам нельзя
вовсе: поля `поход` в них нет.
