# Скачать мост из git на Windows (7.11)

Репозиторий публичный (с 8.11): https://github.com/snipstack-cloud/coss3-bridge
Скачать и обновлять можно без входа. Вход аккаунтом `snipstack-cloud` нужен только для `git push`.

## 1. Поставить Git и Python (один раз)

В PowerShell:

```powershell
winget install --id Git.Git -e
winget install --id Python.Python.3.12 -e
```

Закрыть PowerShell и открыть заново, чтобы появились команды. Проверить:

```powershell
git --version
python --version
```

Если `python` открывает Microsoft Store: Параметры → Приложения → Псевдонимы выполнения приложений → выключить `python.exe` и `python3.exe`, затем открыть PowerShell заново.

Сторонние пакеты Python боту не нужны: живой бот работает на стандартной библиотеке.

## 2. Скачать репозиторий

```powershell
cd C:\Users\$env:USERNAME\Downloads
git clone https://github.com/snipstack-cloud/coss3-bridge.git coss3-git
cd coss3-git
```

Вход не нужен. Окно входа в GitHub (Git Credential Manager) появится только при первом `git push`: нажать «Sign in with your browser» и войти аккаунтом `snipstack-cloud`. Логин запомнится.

Если при `git push` окно не открылось и спрашивают пароль в консоли, обычный пароль GitHub не подойдёт. Нужен токен:
1. https://github.com/settings/tokens → Generate new token (classic).
2. Отметить право `repo`, создать токен, скопировать его.
3. В консоли ввести логин GitHub, а вместо пароля вставить токен.

## 3. Проверить

```powershell
git log --oneline -3
dir загрузчик.py, сетевая_партия.py, РАЗВЕРНУТЬ_НА_ВИНДЕ.md
```

Должны быть свежие коммиты и все три файла.

Если в выводе вместо русских имён файлов кракозябры, выполнить один раз:

```powershell
git config --global core.quotepath off
```

## 4. Обновлять потом

```powershell
cd C:\Users\$env:USERNAME\Downloads\coss3-git
git pull
```

Если `git pull` ругается на локальные изменения, а своих правок нет:

```powershell
git stash
git pull
```

## Дальше

Развернуть бота в игре: `РАЗВЕРНУТЬ_НА_ВИНДЕ.md` в этой же папке. Там вернуть игру к исходным файлам, собрать загрузчик, запустить игру с `-startscript` и запустить `сетевая_партия.py`.

Путь `C:\Users\<имя>\Downloads\coss3-git` в этой инструкции такой же, как в `РАЗВЕРНУТЬ_НА_ВИНДЕ.md`. Если склонировали в другую папку, там поменять `$repo`.
