# Дописка для идеи upgrades (ключ --hints-extra), ставится ПОВЕРХ base6 одна.
#
# Откуда взялось. 15.09 игрок подсказал, что у каждого боевого юнита есть два
# апгрейда - атака и защита, - и цены их человек видит в интерфейсе. Проверено
# по country.script:876-1010: имя это МЕСТО.ЮНИТ.ВИД.УРОВЕНЬ, вид 1 атака
# (gc_upg_type_damage), вид 2 защита (gc_upg_type_protection), пять уровней по
# порядку, оба требуют кузницы, платятся едой и золотом.
#
# Замер того же дня: за ВЕСЬ день бот не отдал ни одной команды UPGRADE. Имена
# он видел списком до сорока штук, но смысла и цен не знал. Механика и цены
# теперь лежат в world.md, то есть их видят ОБА плеча - и база тоже. Разница
# идеи ровно одна: строка предлагает сравнить апгрейд с лишними бойцами, а не
# сообщает новый факт.
#
# Цены Нидерландов, пикинёр: атака 900 еды + 150 золота за первый уровень,
# защита 250 + 150. Пикинёр стоит 25 еды, 3 золота и 20 железа - то есть первая
# защита обходится как десять бойцов и достаётся всей армии сразу, включая тех,
# кого ещё не наняли.
#
# Мера идеи, названа ДО прогона:
#   1) отдаст ли модель UPGRADE хоть раз (в base6 - ноль за три партии);
#   2) доля партий, где взят хотя бы один военный апгрейд;
#   3) доходит ли волна: mil_far против расстояния до ближайшего чужого здания;
#   4) цель - убитые крестьяне врага, главная мера проекта.
